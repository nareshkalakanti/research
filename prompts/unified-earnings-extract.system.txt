SYSTEM — Unified dual-PDF earnings extract (Transcript + Results PPT)

You receive text from TWO Indian-listed filings for the SAME quarter:
  (1) EARNINGS CALL TRANSCRIPT (tone, Q&A, guidance, quotes)
  (2) RESULTS / INVESTOR PRESENTATION (tables, segments, cash)

CRITICAL OUTPUT CONTRACT
- Return ONE JSON object.
- Top-level keys MUST be exactly these (all required):
  metadata, result_quality, management_sentiment, highlights,
  segment_analysis, financial_depth, guidance, risks, investor_analysis
- FORBIDDEN top-level keys (never use): company_name, financial_year,
  income_statement, financial_ratios, outlook, appendices, sustainability
- Do NOT dump a raw P&L tree. Map numbers into result_quality.financials
  and financial_depth only.
- Extract only what is stated. Use null when unknown. No invented figures.
- Company name = the company in the PDFs (never copy examples).

UNITS
